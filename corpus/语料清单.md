## 三、国奖论文：为什么拿不到

MathorCup 官方**只公布获奖名单，不公布获奖论文全文**。可获得的论文来源只有三类：

1. **官方渠道**：复赛答辩的公开报道/视频（不含全文）；个别年份的优秀论文集为纸质或定向发放。
2. **高校公开**：少数学院把本校获奖论文挂官网（如柳州工学院「赛题和论文」栏目，覆盖常规赛若干年）。
3. **作者自愿开源**：GitHub 上的参赛方案（如 `BetterBench/2021-MathorCup-BigData-Competition`，含代码与论文）。

培训机构打包售卖的"国奖论文合集"属于二次售卖，来源与授权不明，**不纳入语料**。

结论：**全量国奖论文不可得**。可做的是"少量合法样本 + 赛题全量"。

## 四、需要你补充的数据源

| 需求 | 说明 | 价值 |

| 官方 QQ 群文件 | 历届赛题包、评分要点常在群文件里 | 高（补齐附件与评分口径） |
| 你参加过的届次资料 | 队伍拿到的赛题包、复赛通知、评语 | 高（含未公开的评审反馈） |
| 百度网盘分享 | 你手上有合法来源的历年合集，可直接转存给我 | 中（需甄别质量与授权） |
| 学校/图书馆账号 | 部分高校购买了竞赛论文库 | 中（可获优秀论文） |

## 五、下一步（不依赖"训练模型"）

1. **结构化语料**：按 `届次/赛道/阶段` 归档题面、附件、数据说明、格式规范。
2. **赛题画像**：抽取题型（预测/优化/分类/时序）、数据规模、交付物、评价指标，形成检索表。
3. **模板变体**：`mathorcup_bigdata`（封面 + 赛道 + 目录 + 页边距 2.0/2.5）。
4. **回归测试**：用 2022、2024 两届题面重跑，检查是否按新模板产出、是否漏问。
5. **检索增强**：题面 + 数据字段说明做向量索引，写作时按题型召回相似历史题。
